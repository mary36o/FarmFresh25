## RESOLUTION
The error was caused by STALE INCREMENTAL COMPILE STATE in AGP. A previous build
(when the default/broken JDK setup was in use) left Gradle believing
EditProductActivity was already compiled, but its .class file was missing. javac
then silently skipped the source file, so `cannot find symbol` appeared in
ItemAdapter.java.

Fix that worked:
  JAVA_HOME=/snap/android-studio/235/jbr ./gradlew clean compileDebugJavaWithJavac
  JAVA_HOME=/snap/android-studio/235/jbr ./gradlew assembleDebug
BUILD SUCCESSFUL. EditProductActivity.class now generated.
